## 正文大纲

### 1. 问题引入（共鸣）

> 每天早上打开 ArXiv，XXX 领域今天又更新了 200 篇论文。一篇篇扫标题看摘要，半小时过去了。最崩溃的是——一周后发现有篇高度相关的工作，当时因为标题不够醒目直接跳过了...

- 科研工作者每天花在论文筛选上的时间
- 传统方式的痛点：低效、易漏、难以量化
- 为什么 RSS/关键词订阅不够用

### 2. 解决方案思路

- 不是替代人读论文，而是把"初筛"自动化
- LLM 的成本已经降到可以规模化使用（一次完整运行几毛钱）
- 核心流程：抓取 → 评分 → 筛选 → 深度分析 → 报告

### 3. 技术实现（有料的部分）

**多源抓取层**
- ArXiv API + OpenAlex + Semantic Scholar
- 20+ 期刊的 RSS/API 整合
- 智能降级策略（期刊 → ArXiv 版本）

**双 LLM 评分系统（核心亮点）**
```
便宜模型预处理（如 GPT-4o-mini / Claude Haiku）
  → 每篇论文按关键词逐项打分
  → 加权求和 + 动态及格线
  → 通过的进入下一阶段

强模型深度分析（如 GPT-4o / Claude Opus）
  → 下载 PDF
  → 提取 7 个分析维度
  → 生成结构化报告
```

**成本优化**
- 便宜模型做初筛，强模型只处理 5-15% 的论文
- Token 追踪系统，每次运行精确统计花费
- 实际数据：一次完整 daily run 约消耗 $0.1-0.5（取决于论文量）

### 4. 趋势研究模式（差异化功能）

- 这是跟其他论文工具最大的区别
- 一行命令分析过去一年某个领域的研究趋势
- LLM 自动生成五个维度的综合分析
- 举例：输入 "quantum error correction"，输出该领域的热点演变、核心研究者迁移、方法论趋势

### 5. 其他亮点

- Docker 一键部署（含自动配置向导，5 分钟跑起来）
- Streamlit Web 面板（浏览器完成所有配置，不需要改配置文件）
- 多通知渠道（Telegram / 邮件 / Bark / 企业微信 / Slack 等）
- WebDAV 同步（坚果云等，多设备共享配置和报告）
- 网络代理支持（国内服务器友好）
- GitHub Actions 支持（完全免费云运行）
- Token 成本可观测
- 中英双语界面
