## 正文

潜水很久，之前做的项目第一次在这里分享。给科研搬砖人做了一个完全开源的工具。

### 一句话介绍

**自动抓取 ArXiv + 20+ 期刊论文 → LLM 智能筛选评分 → PDF 深度分析 → 生成报告推送通知。Docker 一行命令部署，Web 面板配置。**

### 解决什么问题？

读博/做科研的人几乎每天都得刷 ArXiv，但实际痛点很多：
- 每天几百篇新论文，手动筛太累
- 只看标题容易漏掉相关工作
- 不同方向需要不同关键词和权重
- 读了摘要还不够，得下载 PDF 细看
- 想了解某个领域过去一年的研究趋势，手动翻太慢

这个工具就是把这些全自动化了。

### 核心技术特点

**多源抓取**
ArXiv + 20+ 顶级期刊(PRL、Nature、Science 等)，自动检测期刊论文的 ArXiv 版本获取更完整摘要和 PDF。

**双 LLM 评分筛选**
- 便宜模型(CHEAP_LLM)对每篇论文按关键词逐项打分(0-10)
- 按关键词权重 + 动态及格线判断是否进入深度分析
- 支持专家作者加分、参考 PDF 自动提取关键词

**深度 PDF 分析**
通过筛选的论文自动下载 PDF，SMART_LLM 提取7个维度：研究方法、创新点、技术栈、关键结论、局限性、研究关联、未来方向。

**趋势研究模式**
指定关键词和时间范围，批量检索论文，LLM 一次性综合分析：热点话题、时间演变、核心研究者、研究空白、方法论趋势。

### 最近更新(v3.0 → v3.2)

- 🔗 网络代理系统(HTTP/SOCKS5，per-service 粒度)
- ☁️ WebDAV 数据同步(支持坚果云、NextCloud)
- 🖥️ Streamlit Web 面板(7个Tab，浏览器完成所有配置和运行)
- 🐳 Docker 一键部署(含自动配置向导)
- 📊 Token 消耗追踪(每次运行精确统计 LLM 成本)
- 🔒 并发运行互斥锁(防止重复触发)
- 📋 GitHub Actions 支持(手动/定时触发)
- 🌐 i18n 中英双语
- 📝 Markdown + HTML 双格式报告

### 快速开始

```bash
# Docker 一键部署（推荐）
docker compose up -d

# 或本地运行
pip install -r requirements.txt
python main.py
```

Web 面板: `http://localhost:8501`
